# Valhalla Combat Reborn - Skyrim 1.7.x build

The source of **Valhalla Combat Reborn** 1.0.1 by **MichelKI** ([Nexus 196968](https://www.nexusmods.com/skyrimspecialedition/mods/196968)), a rework of Valhalla Combat by dTry (D7ry), with the changes needed to run on **Skyrim 1.7.104** (and 1.6.1170 and newer) with Address Library and alandtse's CommonLibSSE-NG.

- Branch `main`: Reborn's source exactly as its author ships it (the `source` folder of the Nexus download).
- Branch `ng-17x` (default): the 1.7.x changes below, by CageTV. Reborn's behaviour and settings are not changed.

Changes for 1.7.104:
- builds with alandtse's CommonLibSSE-NG (`ng.cmake`, included from an ng build project); the SKSE exports are generated by the build;
- every hook that writes into the game code is checked first (the byte at the call site must be a call into the code section), otherwise it is skipped and logged;
- the melee hit hook is found by the function it calls (Address Library id 38586) and, when another plugin already rewrote that call, attached as a chain after the code around it is verified;
- a Precision post-hit callback processes the hits Precision reports, with a 50 ms de-duplication so one blow is not counted twice;
- skill experience calls pass the four arguments the 1.7 game expects.

This DLL is installed through the installer of [Valhalla A Combat Survival Accord](https://github.com/CageTV/SurvivalAccord) (option "Valhalla Combat Reborn - 1.7 build"); Valhalla Combat Reborn itself must be installed.
